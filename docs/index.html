PIXLZR — Docs

Rust WASM MIT OR Apache-2.0

Density-aware 8×8 DCT image codec with a custom v1 format. The interactive demo is at the project root.

Core documents
  • format.md — normative format v1 spec: header layout, YCoCg, DCT, density/quantization rule, zigzag, zlib framing, worked example, known limitations.
  • architecture.md — what is implemented in v1 and what is still planned (threading, streaming, metrics).
  • wasm-demo-spec.md — WASM demo build/deploy notes and UX spec.
Try it locally
wasm-pack build crates/pixlzr-core --target web --out-dir ../../www/pkg -- --features wasm
python3 -m http.server --directory www 8000
